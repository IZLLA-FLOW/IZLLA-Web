# IZLA

> **Sistemas modernos. Automação inteligente. Presença digital real.**

IZLA é uma startup de tecnologia focada em desenvolvimento web, automação de processos, dashboards empresariais e IA aplicada para pequenas e médias empresas. Nossa missão é transformar operações desorganizadas em sistemas eficientes, com visual profissional e experiência de uso moderna.

---

## Sobre a empresa

A IZLA nasceu da união de dois perfis complementares — backend sólido e automação criativa — com o objetivo de entregar soluções digitais que realmente funcionam para quem mais precisa: pequenas empresas que ainda operam no improviso.

---

## Produtos e serviços

- **Desenvolvimento web** — sites institucionais, landing pages, sistemas web
- **Automação de processos** — N8N, webhooks, integrações com APIs externas
- **Dashboards empresariais** — painéis de métricas e analytics para gestão
- **IA aplicada** — integração de modelos de linguagem em fluxos de negócio
- **Sistemas modernos** — sistemas sob medida para clínicas, imobiliárias, academias

### Produto principal

**Izla Flow** — plataforma de automação e gestão para pequenas empresas (roadmap SaaS)

## Stack tecnológica

### Frontend
- React + Vite + TypeScript
- TailwindCSS + shadcn/ui
- Figma (design)

### Backend
- ASP.NET Core (C#)
- Entity Framework

### Banco de dados
- PostgreSQL (principal)
- MySQL / Supabase / Redis (alternativos)

### Automação & IA
- N8N, Webhooks, APIs externas
- GPT, Claude, ferramentas modernas de IA

- Vercel, Railway, Render
